## 1. 项目概述

### 基本信息
- **游戏名称**：学园都市经营游戏（暂定）
- **游戏类型**：策略/模拟经营
- **目标平台**：微信小程序
- **技术栈**：JS/TS
- **开发周期**：1-2周（MVP版本）
- **游戏模式**：纯单机

### 世界观背景
- **题材来源**：《魔法禁书目录》+《某科学的超电磁炮》
- **背景设定**：学园都市
- **美术风格**：像素风格
- **AI辅助**：美术素材、剧情文案生成

### 玩家身份

玩家是一名能力上限很低但拥有无限成长潜力的学生，偶然加入了一所衰落的名校。

**玩家设定**
- 初始能力：Lv0无能力者
- 特殊体质：无限潜力，可通过剧情解锁新能力
- 成长方式：与Lv4和Lv5角色一起参与故事后，获得对方的部分能力特性
- 能力融合：获得的能力可以通过同类型融合升级

**学校背景**
- 历史：曾是一方通行的母校，因投入所有资源培养一方通行而辉煌
- 没落原因：一方通行被其他势力挖走后，学校被边缘化，人才流失严重
- 玩家状态：不知情者，偶然加入学校
- 与一方通行关系：目标关系，一方通行是玩家追赶的对手

**核心目标**
- 复兴学校：通过培养学员、完成任务、揭秘历史来复兴学校
- 个人成长：通过剧情解锁能力，逐步突破极限
- 最终目标：培养出Lv6等级学员，复兴学校辉煌

### 学校复兴途径

| 途径 | 描述 | 奖励 |
|------|------|------|
| 培养成果 | 培养出高等级学员，提升学校声望 | 学校等级提升、解锁新内容 |
| 任务完成 | 完成各种任务获得资源和声望 | 资源奖励、声望提升 |
| 历史揭秘 | 发现学校历史秘密，解锁隐藏内容 | 隐藏资源、特殊剧情 |

### 双向成长机制

- **玩家→学校**：玩家能力提升，解锁新的培养方式
- **学校→玩家**：随着学校等级提高，能够和更高等级的学校建交，解锁新的任务和可交互角色
- **资源共享**：玩家和学校共享某些资源和效果

## 2. 核心玩法循环

```
招生 → 培养 → 提升能力 → 参加活动/完成任务 → 获得资源/声望 → 建设设施 → 解锁新内容 → 更高难度招生
```

### 详细流程

1. **招生阶段**
   - 主动招生：每回合可选择录取新生
   - 剧情解锁：通过剧情获得特定学员
   - 资源招募：花费资源在学园都市招募

2. **培养阶段**
   - 分配课程：战斗训练、能力开发
   - 自动成长：学员根据课程自动提升能力
   - 风险实验：提升能力上限（有失败风险）

3. **活动阶段**
   - 大霸星祭：学员参加比赛获得奖励
   - 能力考试：定期评估学员能力
   - 校际比赛：与其他学校竞争
   - 理事会审查：声望评估

4. **发展阶段**
   - 建设设施：提升学校能力
   - 完成任务：获得资源和声望
   - 推进剧情：解锁新内容

## 3. 学校等级系统

### 等级划分

| 等级 | 培养能力 | 解锁内容 | 提升条件 |
|------|---------|---------|---------|
| Lv1 | 无能力者→Lv1 | 基础设施、基础课程 | 初始等级 |
| Lv2 | Lv2异能力者 | 新设施、新课程 | 培养成果+设施建设+声望+主线剧情 |
| Lv3 | Lv3强能力者 | 更多内容 | 同上 |
| Lv4 | Lv4大能力者 | 更多内容 | 同上 |
| Lv5 | Lv5超能力者 | 接近原作水平 | 同上 |
| Lv6 | 超越人类极限 | 终极内容 | 完成所有主线剧情 |

### 等级提升条件

1. **培养成果**
   - 培养出对应等级的学员
   - 学员数量达到要求

2. **设施建设**
   - 建设特定设施
   - 设施等级达到要求

3. **声望要求**
   - 公共声望达到一定值
   - 势力好感度达到要求

4. **剧情完成**
   - 完成对应等级的主线剧情
   - 达到1-4的要求后，触发主线剧情
   - 完成主线剧情后，完成等级提升

## 4. 玩家能力系统

### 玩家定位

玩家是游戏的主角，亲自参战，拥有无限成长潜力。核心特点：
- 可以同时掌握多个能力系的技能
- 通过剧情与原作角色互动，获得对应能力系的技能
- 是战斗的核心，其他NPC角色是配合者

### 技能槽系统

**槽位结构**

| 槽位类型 | 数量 | 内容 |
|---------|------|------|
| 主系槽 | 固定 | 大招(1个) + 被动(1个，只能从主系选择) |
| 附系槽 | 随等级增加 | 小技能或被动技能 |

**附系槽成长**

| 玩家等级 | 附系槽数量 | 总技能数 |
|---------|-----------|---------|
| Lv1 | 0 | 2（大招+1被动） |
| Lv2 | 1 | 3 |
| Lv3 | 2 | 4 |
| Lv4 | 3 | 5 |
| Lv5 | 4 | 6 |

**切换规则**
- 非战斗阶段可随意切换技能配置
- 被动1只能从主系的被动技能中选择
- 附系槽可装备任何系的小技能或被动技能

### 主系大招系统

选择某个能力系作为主系后，立即获得该系大招，但效果随系等级提升而成长。

**成长规则**
- 大招名字、描述、效果随等级变化
- Lv1效果较弱，Lv5达到最强形态
- 大招是主系专属，不能装备到附系槽

### 能力系等级提升机制

**提升条件**（需全部满足）

| 条件 | 说明 |
|------|------|
| 剧情解锁 | 完成对应等级的能力者NPC剧情 |
| 研究进度 | 消耗研究点数，达到该等级研究进度100% |
| 熟练度 | 达到指定熟练度阈值 |
| 等级任务 | 找NPC触发并完成等级提升任务 |

**各等级要求**

| 提升等级 | 需要NPC等级 | 熟练度要求 |
|---------|------------|-----------|
| Lv1→Lv2 | Lv2能力者 | 100 |
| Lv2→Lv3 | Lv3能力者 | 200 |
| Lv3→Lv4 | Lv4能力者 | 300 |
| Lv4→Lv5 | Lv5能力者 | 400 |

### 熟练度系统

**获取方式**
- 每使用1次该系技能，熟练度+1

**效果**
- 每10点熟练度 = 该系技能伤害+1%
- 单系封顶500点 = 最高+50%伤害

**设计意图**
- 鼓励玩家多使用某个系，越用越强
- 500点封顶防止无限叠加

### 技能设计规格

**每个能力系 × 每个等级 = 2个技能**

| 技能类型 | 说明 |
|---------|------|
| 主动技能 | 小技能或大招（大招仅主系可用） |
| 被动技能 | 提供持续效果或触发条件 |

**能力系分类（双层设计）**

角色层面（8系）- 用于技能搭配、debuff、连招

| 阵营 | 能力系 | 代表角色 |
|------|--------|---------|
| 科学侧 | 电气系 | 御坂美琴(Lv5)、御坂妹妹(Lv2-3) |
| 科学侧 | 矢量系 | 一方通行(Lv5) |
| 科学侧 | 空间系 | 白井黑子(Lv4)、结标淡希(Lv4) |
| 科学侧 | 心理系 | 食蜂操祈(Lv5) |
| 科学侧 | 流体系 | 婚后光子(Lv4) |
| 科学侧 | 物质系 | 垣根帝督(Lv5)、麦野沉利(Lv5) |
| 科学侧 | 念动系 | 沙淡口麻里(Lv4)、绢旗最爱(Lv4) |
| 魔法侧 | 魔法系 | 茵蒂克丝、神裂火织、史提尔、五和等 |

学院层面（3系+1特殊）- 用于研究、NPC培养

| 学院学科 | 包含角色系 | 顾问来源 | 说明 |
|---------|-----------|---------|------|
| 元素系 | 电气系、流体系 | 御坂美琴、婚后光子 | 自然元素操控 |
| 物质系 | 物质系、念动系 | 垣根帝督、麦野沉利、绢旗最爱 | 物质与念动力 |
| 心灵系 | 空间系、矢量系、心理系 | 一方通行、白井黑子、食蜂操祈 | 空间、方向、精神 |
| 魔法系 | 不可研究 | 茵蒂克丝、神裂火织 | 学园都市不研究魔法，通过剧情获得 |

**特殊机制**
- 幻想杀手（上条当麻）：不参与连招系统，作为剧情机制
- 魔法系：原作中学园都市不研究魔法，魔法系角色通过剧情直接获得，不参与学院研究

**技能总数**
- 8个能力系 × 5个等级 × 2种技能 = 80个技能

### 战斗场景分类

**支线战斗 / 一般任务**
- 玩家自由搭配4个技能槽
- 自成流派，自己输出
- 难度：正常

**主线剧情战 / Boss战**
- 与剧情NPC配合
- 玩家技能需能启动NPC连招才能轻松通过
- 允许玩家硬靠自己输出，但过程较艰难
- 难度：配合轻松 / 硬打难

## 5. NPC配合系统

### NPC定位

NPC是玩家在战斗中的配合者，不是培养对象。核心作用：
- 提供连招配合，帮助玩家轻松通过主线战斗
- 解锁能力系等级提升（需要对应等级的NPC）
- 丰富剧情体验

### NPC获取方式

| 获取方式 | 说明 | 示例 |
|---------|------|------|
| 剧情解锁 | 完成主线/支线剧情后永久获得 | 完成禁书目录篇获得茵蒂克丝 |
| 势力好感度 | 与势力好感度达标后解锁 | 常盘台好感度达标获得白井黑子 |
| 任务奖励 | 完成特定任务获得 | 完成隐藏任务获得稀有NPC |

### NPC入队规则

**支线战斗 / 一般任务**
- 任务相关NPC自动入队
- 玩家自由搭配技能，不需要配合

**主线剧情战 / Boss战**
- 剧情NPC强制入队
- NPC有固定的技能配置
- 玩家需搭配技能配合NPC连招

### NPC连招配合机制

**配合原理**
- 玩家技能触发debuff/状态 → 检测条件 → NPC自动释放技能
- NPC技能也可能触发玩家技能

**配合示例**

```
玩家装备：流体系小技能(潮湿)
NPC配置：御坂美琴(电气系)

玩家：小技能(潮湿) → 敌人潮湿x1
         ↓
【触发】御坂小技能(带电) → 感电扩散
         ↓
玩家：大招(电气系) → 触发御坂大招
         ↓
Boss：被连招击败
```

**不配合的情况**

```
玩家装备：4个电气系技能（纯输出）
NPC配置：御坂美琴(电气系)

玩家：技能1→技能2→技能3→技能4
御坂：无法触发连招，只能普攻
结果：可以打过，但耗时较长
```

## 6. 势力互动系统

### 学校建交机制

随着学校等级提高，玩家可以与更高等级的学校建交，解锁新的任务和可交互角色。

| 学校等级 | 可建交学校 | 解锁内容 |
|---------|-----------|---------|
| Lv1 | 普通学校 | 基础交流任务 |
| Lv2 | 権星高校 | 校际比赛、资源交易 |
| Lv3 | 常盘台中学 | 学员交流、特殊剧情 |
| Lv4 | 名门学校 | 高级任务、稀有角色 |
| Lv5 | 顶尖学校 | 终极剧情、传说角色 |

### 势力列表

| 势力 | 类型 | 关系类型 | 互动方式 |
|------|------|---------|---------|
| 统括理事会 | 学园都市 | 声望评估 | 理事会审查、资源支持 |
| 暗部组织 | 学园都市 | 好感度 | 势力任务、特殊剧情 |
| 主角阵营 | 学园都市 | 好感度 | 招募原作角色、剧情互动 |
| 常盘台中学 | 竞争学校 | 竞争/合作 | 学员交流、校际比赛 |
| 権星高校 | 竞争学校 | 竞争/合作 | 资源交易、势力冲突 |

### 声望系统

**获取方式**
- 完成公共任务：提升公共声望
- 完成势力任务：提升势力好感度

**声望影响**
- 招生质量：声望越高，招生质量越好
- 任务解锁：声望越高，可接任务越多
- 交易优惠：声望越高，交易条件越好
- 审查加分：声望越高，审查评分越高

### 好感度影响

- **解锁招募**：高好感度可招募原作角色
- **资源奖励**：高好感度获得特殊资源/科技
- **剧情解锁**：高好感度触发特殊剧情
- **敌对事件**：低好感度可能触发敌对事件

### 学校互动方式

- **学员交流**：学员间的友谊、竞争关系
- **学校活动**：联合活动、比赛
- **资源交易**：资源、科技的交换
- **势力冲突**：可能发生冲突事件

## 7. 任务系统

### 任务类型

| 类型 | 描述 | 奖励 |
|------|------|------|
| 主线任务 | 学校发展线，原创剧情 | 等级提升、内容解锁 |
| 势力任务 | 各势力发布的任务 | 势力好感度、资源奖励 |

### 主线任务设计

**核心主线**：学校发展线

- 学校从无到有的发展历程
- 每个等级对应一段剧情
- 完成剧情后学校等级提升

**剧情触发**
- 条件触发：达到学校等级、声望、剧情完成度
- 原作事件作为背景，融入原创剧情

## 8. 活动系统

### 活动列表

| 活动 | 类型 | 玩法 | 奖励 |
|------|------|------|------|
| 大霸星祭 | 比赛 | 学员参加比赛，数值对比 | 资源、声望 |
| 能力考试 | 评估 | 定期评估学员能力 | 能力提升 |
| 校际比赛 | 竞争 | 与其他学校的竞争 | 声望、资源 |
| 理事会审查 | 评估 | 声望评估 | 声望影响 |

### 大霸星祭

- **玩法**：学员参加比赛，数值对比
- **机制**：简单计算，学员能力值对比
- **奖励**：根据排名获得资源和声望

### 理事会审查

- **类型**：声望评估
- **评估标准**
  - 学员能力：学员的平均能力等级
  - 设施规模：学校的设施等级和数量
  - 声望影响：学校的声望和影响力
  - 培养成果：培养出的高等级学员数量
- **影响**：定期检查，影响学校声望

## 9. 资源系统

### 资源类型

| 资源 | 描述 | 用途 |
|------|------|------|
| 资金 | 基础货币 | 建设设施、招募学员 |
| 声望 | 学校影响力 | 解锁任务、提升招生质量 |
| 研究点数 | 科技研发 | 解锁科技、提升实验成功率 |
| 材料 | 建设材料 | 建设设施、进行实验 |

### 资源获取

- **设施产出**：设施每回合产出资源
- **任务奖励**：完成任务获得资源
- **活动奖励**：参加活动获得资源

### 资源增长方式

- **产出增加**：设施产出资源增加
- **奖励增加**：任务奖励资源增加
- **新资源**：解锁新的资源类型

## 10. 剧情系统

### 剧情类型

| 类型 | 描述 | 触发方式 |
|------|------|---------|
| 主线剧情 | 学校发展线 | 条件触发 |
| 势力剧情 | 势力互动故事 | 好感度解锁 |
| 原作事件 | 原作剧情融入 | 条件触发 |
| 历史揭秘 | 学校历史秘密 | 探索/任务触发 |

### 剧情触发机制

- **条件触发**：达到学校等级、声望、剧情完成度
- **原作事件**：原作剧情作为背景，融入原创剧情
- **势力剧情**：通过好感度解锁
- **历史揭秘**：通过探索和任务发现

### 原作角色定位

- **先NPC后招募**：剧情中是NPC，特定条件后可招募
- **解锁条件**：完成特定剧情、达到好感度要求

### 剧情内容

- **主线剧情**：学校从无到有的发展历程
- **势力剧情**：与各方势力的互动故事
- **原作事件**：《魔法禁书目录》和《某科学的超电磁炮》中的事件
- **历史揭秘**：学校衰落的真相、一方通行离开的原因、隐藏的研究项目和资源

### 历史揭秘系统

| 揭秘内容 | 描述 | 解锁条件 |
|---------|------|---------|
| 一方通行真相 | 发现一方通行离开的真正原因 | 完成特定剧情线 |
| 研究项目 | 发现学校曾经的秘密研究项目 | 探索学校旧址 |
| 隐藏资源 | 发现学校隐藏的资源和设施 | 完成历史任务 |
| 势力关系 | 发现学校与各方势力的历史关系 | 提升势力好感度 |

## 11. 技术方案

### 技术选型

| 模块 | 推荐方案 | 理由 |
|------|---------|------|

interface Player {
  id: string;

  // 能力系统
