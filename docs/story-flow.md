# 剧情流程与角色加入时机

## 概述

本文档设计游戏的整体剧情流程，明确每个阶段的目标、事件、角色加入时机，用于游戏开发参考。

---

## 玩家背景设定

### 穿越设定

- 玩家穿越到《某科学的超电磁炮》世界
- 没有自己这具身体的记忆
- 初始Lv0无能力者

### 能力觉醒历程

| 阶段 | 剧情 | 能力变化 | 说明 |
|------|------|---------|------|
| 禁书目录篇 | 参与上条当麻遇到茵蒂克丝 | 无能力 | 剧情杀，靠上条当麻肉搏打败boss |
| 幻想御手篇 | 调查幻想御手事件 | 获得御坂美琴的部分能力 | 电气系能力觉醒 |
| 幻想御手篇结束 | 发现能力没有消失 | 又获得白井黑子的能力 | 空间系能力觉醒，达到Lv1 |
| 入学剧情 | 正式入学 | 开始系统学习 | 此时才安排入学 |

### 身世揭示（后期剧情）

- 后期发现玩家是一方通行的克隆体
- 解释无限成长能力的来源
- 解释晋升Lv6的可能性

---

## 角色等级设定

### 原作角色

- 前期遇到的原作角色：就是其在剧情中的等级（不设初始等级）
- 高等级原作角色：只有主线剧情时才能成为队友
- 保持原作设定，不人为降低等级

### 常驻队友

- 只能玩家在学校里面找学生/老师
- 学生/老师随机拥有单系能力和技能
- 玩家可以挑选培养

### 玩家等级

- Lv0→Lv1：幻想御手篇结束，获得两个系能力后
- Lv1→Lv4：通过提升各系等级
- Lv4→Lv5：最后阶段才算

## 第一阶段：穿越觉醒（Lv0）

### 阶段目标

- 了解世界观
- 体验原作剧情
- 获得初始能力

### 主线剧情

**剧情1：禁书目录篇**

| 项目 | 内容 |
|------|------|
| 触发条件 | 游戏开始 |
| 剧情概要 | 玩家穿越，遇到上条当麻和茵蒂克丝，参与禁书目录事件 |
| 战斗安排 | **无玩家战斗**，剧情杀，靠上条当麻肉搏打败boss |
| 玩家作用 | 旁观者、辅助者，了解世界观 |
| 奖励 | 无能力获得，了解魔法侧与科学侧的对立 |

### 角色出现

| 角色 | 出现方式 | 说明 |
|------|---------|------|
| 上条当麻 | 剧情出现 | 主角，保护茵蒂克丝 |
| 茵蒂克丝 | 剧情出现 | 被追捕的对象 |
| 神裂火织 | 剧情出现 | 追捕者 |
| 史提尔 | 剧情出现 | 追捕者 |

### 阶段特点

- 玩家无战斗能力
- 纯剧情体验
- 了解世界观和角色关系

## 好感度系统

### 好感度获取方式

| 方式 | 好感度增加 | 说明 |
|------|-----------|------|
| 完成剧情 | +50 | 完成该角色相关剧情 |
| 战斗配合 | +10 | 与该角色一起战斗 |
| 赠送礼物 | +5-20 | 根据礼物品质 |
| 完成任务 | +20 | 完成该角色发布的任务 |

| 等级 | 好感度 | 解锁内容 |
|------|--------|---------|
| 陌生 | 0-50 | 基础对话 |
| 熟悉 | 51-100 | 解锁支线剧情 |
| 朋友 | 101-150 | 解锁特殊对话 |
| 亲密 | 151-200 | 解锁隐藏剧情 |
| 挚友 | 201+ | 解锁终极剧情 |

| 角色 | 解锁剧情所需好感度 | 说明 |

## 学院NPC系统

### NPC获取方式

| 获取方式 | 说明 | 举例 |
|---------|------|------|
| 学院自动生成 | 学院等级提升后自动生成新NPC | 学院Lv2生成Lv2 NPC |
| 任务奖励 | 完成特定任务获得特殊NPC | 完成隐藏任务获得稀有NPC |
| 声望解锁 | 学校声望达到一定值解锁 | 声望500解锁高级NPC |

### NPC培养

| 培养方式 | 效果 | 说明 |
|---------|------|------|
| 课程训练 | 提升NPC能力等级 | 消耗资源 |
| 装备强化 | 提升NPC属性 | 消耗材料 |
| 技能学习 | 学习新技能 | 消耗研究点数 |

### NPC等级

- NPC等级受学院研究等级限制
- 学院研究等级通过剧情顾问提升
- NPC可以成为常驻队友，参与战斗
