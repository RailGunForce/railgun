# 战斗系统设计文档

## 概述

本文档记录学园都市经营游戏的战斗系统设计，采用回合制 + 插队机制，配合 Debuff 反应和连招链系统，体现不同能力系的差异化。

---

## 核心机制

### 1. 行动条系统

战斗采用行动条驱动的回合制，显示敌我双方所有单位的行动顺序。

```
行动条：[白井] → [敌A] → [御坂] → [敌B] → [婚后] → [敌C]
```

**基础规则**：
- 按照行动条顺序依次执行每个单位的行动
- 轮到敌方时自动执行攻击或技能
- 当前行动单位高亮显示

**插队机制**：
- 大招：玩家手动点击，随时可插队释放
- 自动小技能：满足条件时自动插队释放
- 优先级：玩家大招 > 自动小技能 > 基础行动条

**控制状态**：
- 被眩晕/压制的单位跳过行动
- 行动条继续推进到下一个单位

---

### 2. 充能系统

大招需要充能到 100% 才能释放。

**普通充能**（大部分角色）：
- 攻击时充能 +10%
- 被攻击时充能 +5%

**特殊充能**（个别强力角色）：

| 充能类型 | 机制 | 适用角色定位 |
|---------|------|-------------|
| 连击充能 | 队伍累计攻击次数达标时充满 | 追击型角色 |
| 受击充能 | 队伍累计损失生命达标时充满 | 坦克/反击型角色 |
| 治疗充能 | 队伍累计回复生命达标时充满 | 辅助型角色 |

**充能重置**：大招释放后充能归零，重新积累。

---

### 3. Debuff 系统

#### 基础 Debuff 类型

| 能力系 | Debuff | 叠层触发 | 遇其他系触发 |
|-------|--------|---------|-------------|
| 电气系 | 带电 ⚡ | 4层 → 眩晕1.5秒 | 遇潮湿 → 3x3感电扩散 |
| 流体系 | 潮湿 💧 | 3层 → 减速30% | 遇带电 → 感电扩散 |
| 心理系 | 干扰 💭 | 2层 → 攻击力-20% | 遇带电 → 混乱（攻击友方）|
| 矢量系 | 偏转 ↗️ | 3层 → 强力反弹 | — |
| 空间系 | 扰乱 🌀 | 2层 → 强制位移 | — |
| 物质系 | 崩坏 💥 | 3层 → 防御力-30% | 遇扰乱 → 物质湮灭（额外伤害）|
| 念动系 | 束缚 🔒 | 2层 → 无法行动1秒 | 遇偏转 → 解除反弹 |
| 魔法系 | 诅咒 📿 | 3层 → 持续掉血+减速 | 遇干扰 → 魔法反噬 |

#### 叠层规则

- 技能命中时叠加 1 层
- 头顶显示 Debuff 图标和层数（如 ⚡x3）
- 达到阈值立即触发效果

#### 反应规则

- 不同系 Debuff 组合触发额外效果
- 反应后参与反应的 Debuff 可能被消耗

#### 持续时间

- 每个 Debuff 有固定持续时间
- 超时自动清除，层数归零

---

### 4. 连招链系统

**核心逻辑**：大招命中 → 触发队友自动小技能 → 形成连锁反应

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   玩家点击：白井黑子【大招：空间压制】                            │
│   ↓                                                             │
│   敌人被挂上 [控制] 状态                                         │
│   ↓                                                             │
│   【自动触发】检测[控制] → 御坂小技能【雷击之枪】                │
│   敌人带电 x1                                                    │
│   ↓                                                             │
│   【自动触发】检测[带电] → 婚后小技能【真空刃】                  │
│   3x3 范围感电扩散                                               │
│   ↓                                                             │
│   连招结束，等待下一个大招                                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**限制机制**：
- 连招链深度上限：3 层（可配置）
- 小技能有冷却时间，冷却中无法触发
- 连招链达上限后等待下一次大招

**UI 提示**：
- 连招触发时显示提示："[控制] → 自动触发 [雷击之枪] → [带电x3]"
- 连招结束后提示消失

---

### 5. 辅助反制系统

辅助角色可以打断敌方连招链，保护我方。

| 功能 | 机制 | 示例 |
|-----|------|------|
| 清除 Debuff | 辅助技能移除我方 Debuff | 茵蒂克丝驱散负面状态 |
| 控制敌人 | 眩晕/压制/混乱打断敌方行动 | 食蜂操祈混乱敌人 |
| 护盾 | 抵挡伤害、免疫控制 | 一方通行矢量护盾 |
| 加速 | 提前我方行动条 | 空间系瞬移加速队友 |

**插队规则**：
- 辅助大招可在敌方连招链进行中插队
- 打断敌方连招，为我方争取输出窗口

---

### 6. 配队系统

每场战斗可上场 4 个角色。

**角色定位**：

| 定位 | 功能 | 示例角色 |
|-----|------|---------|
| 输出 | 高伤害、Debuff 叠层 | 御坂美琴 |
| 控制 | 控制效果（眩晕、压制） | 白井黑子 |
| 辅助 | 清 Debuff、护盾、治疗 | 茵蒂克丝 |
| 坦克 | 承伤、反击 | 一方通行 |

**配队策略**：
- 连招链搭配：选择技能可连锁触发的角色
- 反制搭配：带辅助角色应对敌方连招
- 根据敌方配队调整策略

## 战斗流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        完整战斗流程                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   1. 战斗开始，显示行动条                                        │
│                                                                 │
│   2. 行动条推进，轮到某单位                                      │
│                                                                 │
│   3. 我方单位行动：                                              │
│      - 自动攻击（无特殊效果）                                    │
│      - 或等待玩家点击大招（充能满时）                            │
│                                                                 │
│   4. 大招命中 → 挂 Debuff → 检测自动小技能触发                  │
│                                                                 │
│   5. 自动小技能插队释放 → 叠层/反应 → 可能触发下一个             │
│                                                                 │
│   6. 敌方单位行动：                                              │
│      - 自动攻击或技能                                            │
│      - 被控制时跳过                                              │
│                                                                 │
│   7. 玩家决策：是否用辅助大招打断敌方连招？                      │
│                                                                 │
│   8. 循环直到一方全灭                                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 关卡难度设计

| 难度 | 敌方配队 | 玩家策略 |
|-----|---------|---------|
| 简单 | 纯输出，无配合 | 硬扛输出，随便打 |
| 中等 | 有 1 个控制敌人 | 带辅助清 Debuff |
| 困难 | 敌方有完整连招链 | 用控制打断敌方连招 |
| Boss | 连招 + 辅助反制 | 预判敌方行动，选择最佳时机 |

---

## 战斗演出

采用像素风格，通过镜头语言弥补动画不足：

| 技能类型 | 演出方式 |
|---------|---------|
| 普攻 | 无特殊动画，自动进行 |
| 小技能 | 镜头拉近 + 简单特效（1-2 秒） |
| 大招 | 全屏特效 + 屏幕震动 + 停顿（2-3 秒） |

**镜头控制**：
- 普通状态：全景，看到双方站位
- 技能释放：镜头拉近到目标
- 大招：全屏特效 + 震动

## 示例连招

### 连招 1：电磁控制流
```
白井大招(控制) → 御坂小技能(带电) → 御坂大招(全体带电) → 全体眩晕
```

### 连招 2：感电扩散流
```
婚后大招(潮湿) → 御坂小技能(带电) → 触发感电扩散 → 御坂大招收割
```

### 连招 3：心理干扰流
```
食蜂大招(心理干扰) → 御坂小技能(带电) → 食蜂小技能(混乱) → 敌人互打
```
